# Accessible Windows OS

The `os` branch is an independent, from-zero operating-system line.

## Non-negotiable line

- The OS must remain structurally independent from Windows, Linux, Android and macOS.
- Accessibility is not an API, service, framework or optional layer. It is an invariant of every system component.
- Cognition, memory, security, storage, recovery and human interaction are designed as intrinsic properties of one system.
- Firmware, boot, kernel, filesystem, drivers and user environment are developed as native components of this OS.
- GitHub Actions is the authoritative build, test and validation pipeline.
- A feature is not declared complete without reproducible evidence.

See `docs/CONSTITUTION.md` and `docs/ARCHITECTURE.md`.
