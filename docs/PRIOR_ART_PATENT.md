# Patent and prior-art discipline

For foundational mechanisms, search names, concepts, patent families and independent claims before implementation is treated as cleared.

A C proof requires a documented feature definition, relevant patent families, priority/status/jurisdiction review, independent-claim comparison and design-around where necessary.

Current research has already shown adjacent patents in self-healing systems, capability-based agents, ownership analysis, semantic action graphs and prompt-injection mitigation. Therefore C defaults to `UNPROVEN`.
