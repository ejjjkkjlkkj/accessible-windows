# Sovereign architecture

The architecture is defined by our primitives, not by compatibility with another OS.

## Native order

1. Seed-0 and machine boundary.
2. Project-owned instruction encoder.
3. Project-owned object/image format.
4. Project-owned linker/emitter.
5. AWL compiler.
6. Proof/verifier engine.
7. Native kernel.
8. Native memory/authority/cell model.
9. Native storage object graph.
10. Native device cells.
11. Native semantic/human-I/O fabric.
12. Native cognition and memory.
13. Native applications/tools.
14. Compatibility only at external boundaries.

## One organism

Security, accessibility, cognition, memory, regeneration and interaction are not optional layers.

Every cell has identity, generation, explicit authority, provenance, semantic obligations, regeneration rules and A+B evidence obligations.

## Compatibility

Foreign executable formats, APIs, filesystems or application models may be supported later through boundary translators.

A compatibility translator may depend on the native architecture. The native architecture never depends on a compatibility translator.
