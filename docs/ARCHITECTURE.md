# Qevarynox architecture

Qevarynox is one software organism, not an OS plus frameworks.

Native order:
1. Seed and machine boundary.
2. Native instruction encoder.
3. Native object/image formats.
4. Native linker/emitter.
5. Qevarynox language compiler.
6. Proof engines A+B+C+D.
7. Kernel core.
8. Memory/authority/cell model.
9. Regenerative genome+morphology.
10. Storage/network/device cells.
11. Semantic human-I/O fabric.
12. Cognition and memory.
13. Native productivity/media/communication capabilities.
14. Compatibility only at external boundaries.

Security, accessibility, cognition, memory, regeneration and human interaction are language/system semantics, not add-on frameworks.

Cognition may propose intent but cannot mint authority, lower the security floor, mutate the verified genome or disable accessibility.
