# A+B+C+D proof model

A = structural proof.
B = independent runtime/reconstruction/adversarial proof.
C = patent/prior-art review at the mechanism and independent-claim level.
D = code-origin provenance.

PASS is explicit. UNPROVEN means evidence is incomplete. FAIL means evidence contradicts the invariant.

A and B must be independent.
C cannot be passed by a name search or a zero-result web query.
D records our source lineage and must not be misrepresented as worldwide uniqueness.

GitHub Actions is an external bootstrap witness only and cannot satisfy final sovereign self-hosting.
