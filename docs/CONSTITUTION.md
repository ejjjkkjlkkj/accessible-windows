# Qevarynox constitution

## Zero software ancestry
No existing OS, kernel, language runtime, compiler framework, filesystem, accessibility framework, AI framework, UI toolkit, antivirus, office suite or bootloader is an implementation base.

## Hardware boundary only
CPU ISAs, buses, devices, firmware interfaces and public standards may be implemented from documentation because real hardware requires them. They do not define the internal software architecture.

## One organism
Language, compiler, kernel, security, accessibility, cognition, memory, regeneration, storage, network, development tools and native applications are parts of the same system.

## No ambient authority
Execution grants no authority. Authority is explicit, scoped, provenance-bearing, generation-bound, revocable and non-self-expanding.

## Regeneration
Genome defines what can be built. Morphology defines what should exist. Memory is mutable lived/learned state. A compromised cell never repairs itself from compromised state.

## Accessibility
No boot, recovery, security, developer, diagnostic, cognitive or maintenance path is exempt.

## Proof
Foundational claims require the applicable A+B+C+D evidence. Missing evidence is `UNPROVEN`.

## Claim discipline
No global claim of being better, secure, accessible, sovereign, self-hosted or bootable is permitted without property-specific evidence.
